# Alpha Ridge Capital — ESADE Asset Management

Team project site for the quant fund pitch (Alpha Ridge Capital, multi-asset trend-following CTA).

**Live site:** [inesassetmanagement.vercel.app](https://inesassetmanagement.vercel.app)

## Contents

- `index.html` — pitch site (strategy, back-test results, allocator slider, Q&A prep)
- `i18n.js` / `arc-content.js` — English, Spanish, and Portuguese language switcher
- Chart PNGs exported from `quant_appendix.ipynb`

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

Push to `main` on this repo; Vercel redeploys automatically if connected to the GitHub project.
